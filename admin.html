Website editor

One-time setup on this computer

To save changes, the editor needs a GitHub token that can write to your website repository. It stays only in this browser.

  1. Open GitHub: new fine-grained token.
  2. Name it "website editor". Repository access: Only select repositories → yashv373.github.io.
  3. Permissions → Repository permissions → Contents: Read and write. Then generate and copy it.
